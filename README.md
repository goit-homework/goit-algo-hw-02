# goit-algo-hw-02

Домашнє завдання 2 — структури даних: черги.

## Завдання 1 — сервісний центр

Імітація сервіс-центру з оператором Степаном. Використовує `queue.Queue`.
Заявки мають id, опис проблеми і пріоритет, обробка займає випадковий час.

```bash
python3 task1.py
```

Команди в інтерактивному режимі:

| Команда | Що робить                            |
|---------|--------------------------------------|
| `g`     | створити одну заявку                 |
| `p`     | обробити одну заявку                 |
| `q`     | вийти і показати підсумок            |
| Enter   | авто: 1–3 нові заявки + одна обробка |

На виході — лічильник створених, оброблених і тих, що лишилися в черзі.
